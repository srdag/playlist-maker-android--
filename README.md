# PlaylistMaker

Приложение для поиска музыки и управления плейлистами. Проект выполнен в рамках курса Android-разработки.

## О проекте
PlaylistMaker позволяет искать треки.

### Основные возможности
- **Поиск**: Поиск музыкальных композиций с использованием MVVM и Clean Architecture.
- **Настройки**: Возможность поделиться приложением, связаться с поддержкой и прочитать пользовательское соглашение.
- **Навигация**: Реализована на базе Jetpack Compose Navigation.

---

## Технологический стек
- **Язык**: Kotlin
- **UI**: Jetpack Compose
- **Архитектура**: MVVM, Clean Architecture
- **Сетевые запросы**: -
- **Управление состоянием**: StateFlow

---

## Технические требования
- **JDK**: 11 или 17
- **Android Studio**: Ladybug (или новее)
- **Min SDK**: 29 (Android 10.0)
- **Target SDK**: 36 (Android 15)
- **Gradle**: 8.x

---

## Как запустить проект

1. **Клонирование репозитория**
   ```bash
   git clone https://github.com/srdag/playlist-maker-android--.git
   ```

2. **Открытие в Android Studio**
   - Запустите Android Studio.
   - Выберите `Open` и укажите путь к корневой папке проекта.

3. **Сборка и запуск**
   - Дождитесь завершения Gradle Sync.
   - Выберите устройство или эмулятор (API 29+).
   - Нажмите кнопку `Run` (зеленый треугольник).

---

## Структура проекта
- `data/` — Реализация репозиториев, сетевые запросы, DTO.
- `domain/` — Бизнес-логика, интерфейсы репозиториев, модели данных.
- `ui/` — Экранные компоненты (Compose), ViewModel и тема оформления.
- `creator/` — Инструменты для создания зависимостей.
- `navigation/` — Конфигурация NavHost и маршрутов.
