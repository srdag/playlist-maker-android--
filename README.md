# Playlist Maker

## Описание проекта
Playlist Maker — это Android-приложение для меломанов, которое позволяет искать любимые треки в iTunes API, добавлять их в список избранного и организовывать в персональные плейлисты.

## Основные функции
- **Поиск**: Поиск треков через iTunes Search API с поддержкой истории запросов.
- **Медиатека**: Разделы с избранными треками и плейлистами.
- **Плейлисты**: Создание, редактирование и удаление плейлистов, добавление/удаление треков.
- **Детали трека**: Подробная информация о песне и возможность быстрого добавления в плейлист.
- **Темная тема**: Автоматическая и ручная поддержка темной темы.

## Стек технологий   
- **Язык**: Kotlin
- **UI**: Jetpack Compose
- **Архитектура**: MVVM (Clean Architecture layers)
- **Блокчейн / Сеть**: Retrofit2, Gson
- **База данных**: Room
- **Хранение настроек**: Jetpack DataStore (Preferences)
- **Загрузка изображений**: Coil
- **Навигация**: Jetpack Compose Navigation

## Требования к среде разработки
- **Android Studio**: Ladybug (2024.2.1) или новее
- **Kotlin**: 2.0.21
- **Gradle**: 8.x
- **Min SDK**: 29
- **Target SDK**: 36

## Сборка и запуск
1. Клонируйте репозиторий: `git clone <ссылка_на_репозиторий>`
2. Откройте проект в Android Studio.
3. Дождитесь завершения синхронизации Gradle.
4. Выберите эмулятор или физическое устройство (API 29+).
5. Нажмите кнопку **Run 'app'**.
